# Meeting to MOM Generator

## Project Overview

This project uses n8n and AI to automatically convert meeting notes into a structured Minutes of Meeting (MOM).

## Objective

The main objective is to reduce the time required to prepare meeting minutes manually.

## Workflow

Meeting Notes → n8n → AI Processing → Structured MOM → Save/Send

## Main Features

- Accept meeting notes
- Extract important information
- Identify decisions
- Identify action items
- Identify responsible people
- Identify deadlines
- Generate a professional MOM
- Store or send the generated MOM

## Technologies Used

- n8n
- AI
- GitHub
- Google Docs / Google Sheets
- Gmail

## Future Improvements

- Voice-to-text meeting input
- Automatic meeting recording transcription
- WhatsApp/Slack integration
- Automatic calendar integration
